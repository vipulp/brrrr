# BRRR Real Estate Investing Toolkit

A growing, open-source toolkit for **real estate investing**, starting with the **BRRR strategy** (Buy, Rehab, Rent, Refinance, Repeat) and expanding over time into broader deal analysis, workflows, automation, and portfolio tools.

This project showcases both **technical skill** (Python, JS, notebooks, CLI tools) and **real estate investing expertise**, while remaining genuinely useful for investors at all levels.

  - Anyone evaluating rental or value-add deals

## BRRR Strategy Overview

BRRR stands for:

- **Buy** – Acquire a property below its After-Repair Value (ARV).  
- **Rehab** – Improve it to rental-ready condition and force appreciation.  
- **Rent** – Stabilize income with a tenant.  
- **Refinance** – Pull capital back out via cash-out refinance.  
- **Repeat** – Recycle capital into the next deal.
